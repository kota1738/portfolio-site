02DEVICES

Selected work

  1. REC_01 Infrastructure 2024 — present

    Self-hosted Linux service stack

    Fourteen containerised services on ARM64 Fedora with SELinux enforcing, defined in a single Docker Compose file. Egress for selected containers is policy-routed through a Gluetun VPN gateway; Pi-hole handles DNS filtering for the network; n8n runs scheduled automation. Backups run on a schedule with rsync.

    Public services are exposed through a Cloudflare Tunnel — an outbound-only connector, so there is no port forwarding and no inbound port open on the network. Rebuilds and redeploys are scripted end to end.
